# Troubleshooting

## Offline

Confirm the current IP, same non-guest network, enabled ADB debugging, and TCP port 5555. A router or Fire TV restart can change the IP.

## Unauthorized

Accept the RSA prompt on the TV. If absent, toggle ADB debugging off/on and clear prior debugging authorizations if Fire OS offers that control.

## Home briefly shows Amazon

Do not disable Amazon Home. Routing differs by build; use only a validated profile/helper. A short Amazon flash cannot always be removed without unsafe privileged changes.

## Settings missing

Open preserved Amazon Settings. Restore immediately if Settings, Bluetooth, HDMI, Display, Sound, or network controls are missing.

## Apps, logins, or playback fail

Stop mutations. Check accounts, Appstore, DRM, download manager, storage, time, and network. Retail ADB cannot restore lost private app data. Restore package/settings changes before signing in again.

## Volume or Cube speaker

HDMI-CEC, receiver, TV, and internal Cube speaker routing are separate. Internal media output is model/build-limited; capability detection cannot override hardware or Fire OS safely.
