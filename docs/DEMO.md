# Demo

Run `bash scripts/demo.sh --fixture tests/fixtures/raven-inspection.json` for a deterministic redacted walkthrough. It prints identity, compatibility policy, launcher choices, backup requirements, preserved services, and verification coverage without connecting to a device.

For a live demo, use a non-primary test Fire TV, capture a fresh baseline, show every plan, and demonstrate uninstall/restore. Never record serial numbers, accounts, Wi-Fi details, or ADB keys.
