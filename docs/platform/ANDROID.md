# Android companion guide

Choose `arm64` for modern 64-bit phones/tablets and `armv7` only for older 32-bit ARM devices. Allow the browser or file manager to install unknown apps, sideload the APK, then turn that permission off again.

The companion controls a separate Fire TV on the same trusted network; it is not a replacement launcher. Enter the Fire TV IP, accept the RSA prompt shown on the television, inspect, and back up before applying changes.

The GitHub APK is release-optimized and signed with the project's community release key. Android upgrades must use an APK signed by the same key; otherwise uninstall the older test companion first. Uninstalling the companion does not undo Fire TV changes—use Restore in the companion before removing it.
