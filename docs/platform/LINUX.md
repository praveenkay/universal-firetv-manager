# Linux guide

Download the AppImage or Debian package. For an AppImage, run `chmod +x *.AppImage` and launch it. For Debian/Ubuntu, install the `.deb` with `sudo apt install ./<package>.deb`.

The desktop UI requires WebKitGTK. Enter the Fire TV's numeric IP, accept the RSA prompt, inspect compatibility, and create a backup before applying a plan. A portable `firetvctl-linux-x86_64` binary is also included.

Verify the release with `sha256sum -c SHA256SUMS`.
