# Package metadata

This directory contains metadata only. The repository does not redistribute Projectivy or third-party APKs.

The client offers compatible launcher choices, obtains an APK from the user or its upstream release, extracts its package and signing identity with the platform verifier, and asks `firetv-core` to verify that identity and the file hash before installation.

Projectivy is always user-supplied. Its premium license remains between the user and Projectivy. Open-source choices link to their upstream repositories so license and release provenance remain visible.
